**均值身份仍有待解释的差异。** moving 两窗中，Camera／面积 SAH／75:25 的整图蓝通道均值约 0.000603，而 Prefix／全局对角线约 0.000581；朝上连通面的蓝通道约 0.004052 对 0.003897。该重复差异超过各自两窗波动，不能直接称作普通随机噪声。接收颜色／几何、灯和体素已核对，但本组未保存发光面 UV 表；两种全局树源码只差冻结节点数据。下一次同作业对照需核对面 UV 与实际发光输入，并区分输入漂移、有限窗口漏采和真实估计器问题。现有统计是筛选线索，不能用来宣称亮度恒定或无偏已经实证通过。

**不能直接剔除所有贴着实心邻居的灯面。** 当前终点接受条件核对材质及距离小于 0.01，没有核对目标体素身份。已有 M2 在全部候选可见面都被这种规则排除的灯上仍有正贡献；独立 CPU 几何重放也找到先命中相邻同材质发光体、距目标点约 0.00664 的有限内部面位置，见[反例](../../../builds/light-sampling/20261108-eight-hour-exploration/neighbor-hit-witness.json)。这不是 GPU 逐样本归因，却足以否定“这些方向必为零”的前提。本轮不改终点语义；实验候选改为 25% 原面分布 + 75% 重加权分布，同材质邻面保留，所有原支持保留，并评价混合后的真实 PDF。GPU 64 个记录中 44 个触发重加权，灯内 PDF 的最大相对差约 1.72e-4；仍需整图及跨场景验收。

新增廉价权重筛查只使用已有 AABB：投影半径、均匀正半空间均值／RMS 和包围球锥的精确最大余弦。前两类在 moving 顶面／部分侧面退化；球锥候选在已有 M2 上较均衡，无新增节点读取／统计，但还没有实际成本与整图收益。对于单位接收法线，令 `h=dot(n,delta)`、`d²=dot(delta,delta)`、`r²=dot(half,half)`；接收点在球内时取 1，否则令 `s=sqrt(d²-r²)`，`h>=s` 时取 1，其余取 `(h*s + sqrt(max(d²-h²,0))*sqrt(r²))/d²`，再沿用原余弦下限及半空间拒绝。[离线结果](../../../builds/light-sampling/20261108-eight-hour-exploration/offline-cosine-moment-screen.json)只筛选下一批候选，不证明全图泛化。

#### 固定发光输入与动态粗簇复查（2026-11-09 07:50 UTC）

后续同作业重测中，Camera／全局对角线的旧蓝通道均值差消失；同时实际捕获到发光面 UV 表变化。测量夹具改为读取相同的固定 UV 表，保留实际纹理、发光读取与终点判定。moving-4 的两份独立配对中，全局对角线／上层 Near/Far 75:25 的尾部 `V*T` 分别约为各自 Camera 控制的 `0.746`／`0.887`；讨论端直接重算原始数据与计时，结果一致，见[对角线复查](../../../builds/light-sampling/20261108-eight-hour-exploration/independent-moving4-fixed-uv-diagonal-first-review.json)及[75:25 复查](../../../builds/light-sampling/20261108-eight-hour-exploration/independent-moving4-fixed-uv-near-first-review.json)。这支持收益仍存在，不证明旧差异完全由 UV 导致。所采 lava/fire 图集裁块在同作业内首尾一致，但跨作业颜色图集仍变化；35 种发光材质没有全部冻结，不能合并跨作业均值作为完整同发光输入。固定 UV 的额外读取也须与最终生产路径计时区分。

动态粗簇候选 `11cb4137` 已实际运行：保留 64³ 世界块内的 Prefix 子树，以最多 125 个粗根重新构建 G16 四叉上层，采用通量乘 AABB 对角线平方的拆分代价。讨论端另写直接二进制读取器，独立确认 ls1／ls5／moving-4 的 10,235／2,172／4,243 盏灯完整，42／20／54 个粗根内的七个边界／质量字段、材质、非空孩子顺序完全保留；不要求物理孩子地址或空槽布局相等。首尾语义树相同，内部质量相对误差最大约 `1.15e-7`，见[独立结构复查](../../../builds/light-sampling/20261108-eight-hour-exploration/independent-coarse-structure.json)。两个场景的 CPU float64 拓扑与 GPU 不同，但按原运算顺序的 float32 左侧 FMA 重放精确匹配，不是漏灯证据。

| ls1 | 约 0.927 | 约 1.58 | 顶面代价仍明显 |

三景整图原始统计均已独立复算。moving 的同作业 Prefix／粗簇 raygen 均值为 4.658／4.116 ms，但各构建 pass 的中位时间之和从约 0.498 增至 1.170 ms，最后阶段从 0.117 增至 0.789 ms；根数少并不等于构建便宜。下一版复用上层原有 284 个槽（最多需要 248 个子记录），并以固定顺序并行计算三轴代价；源码检查未发现容量或 barrier 分歧，尚待实机与跨界验证。当前仍无通用默认通过验收。

对整片亮度噪声另保留空间尺度检查：将两段 32 帧线性均值之差在 16²／64² 共同覆盖区域内先平均，再计算平方范数的一半。它用于发现逐像素方差未体现的低频变化，一对窗口不足以确立相关性或输入漂移的来源。逐像素独立近似下，该量的期望为 `sum(V1+V2)/(64*N²)`，其中 N 为块内有效像素数；不把该近似当作真实相关性模型。

六向邻接摘要是待实验的软权重：按节点到接收点的方向混合六个开放方向质量，并保留 25% 原质量下限，不硬剔除灯或灯面。[离线量化筛查](../../../builds/light-sampling/20261108-eight-hour-exploration/offline-escape-quantization-screen.json)中，逐层递归 UNORM8 保留了 28 个既有 M2 窗的改善，较未量化摘要的最大方差增加约 0.114%，可存成独立 8B 记录；这不证明整图收益或 GPU 成本。另一个[仅改构建代价的筛查](../../../builds/light-sampling/20261108-eight-hour-exploration/offline-exposure-clustering-screen.json)改善顶面、恶化原本较安静的新红柱，保留整图实验资格，不再以单点相对回退直接淘汰。

#### 实际跨砖、粗层成本与灯内数值反例（2026-11-09 08:40 UTC）

粗层并行分桶保持串行方案的有序拓扑，moving-4 最后构建阶段的中位时间约从 0.789 降到 0.396 ms，各构建 pass 中位时间之和约从 1.170 降到 0.778 ms。更便宜的候选 `15df1311` 保留世界 64³ 块内子树，以活跃粗根的最小世界坐标作为 Morton 相位锚点；完整构建的对应和约 0.484 ms，同作业 Prefix 约 0.499 ms。这里的中位数之和不是“总时间的中位数”。它也不是固定世界原点前缀：相同灯输入保持分组，新增或移除最小边界灯仍可能改变锚点。

讨论端直接复算 moving-4 原始两窗，anchor 的 raygen 均值约 4.164 ms，整图最差 5% 方差乘均值时间约为旧 Camera 控制的 0.79 倍；并行分桶约 0.75 倍，见[anchor 独立复查](../../../builds/light-sampling/20261108-eight-hour-exploration/independent-moving4-anchor-first-review.json)及[并行分桶复查](../../../builds/light-sampling/20261108-eight-hour-exploration/independent-moving4-parallel-first-review.json)。这是共同接收像素的单场景筛选，Camera 仍是跨作业参照，不足以接受为通用默认。

实际连续移动已验证这条轨迹上的分组稳定性。两次作业的 28 个实际位姿一致；从原始 GPU trace 穷举对齐均得到唯一连续 26 帧。offset 8 与 24 分处 x=112 的两侧，共享 4,042 灯的两路交换无关指纹。Camera 的有序树指纹和节点数改变；Prefix、粗层分桶及 anchor 均保持不变。新旧作业的 Prefix trace 连文件哈希也相同，见[独立跨界复查](../../../builds/light-sampling/20261108-eight-hour-exploration/independent-anchor-motion.json)。这些有限指纹不覆盖内部包围盒／质量，也不是完整输入的加密证明；其他位姿的灯集合会变化。诊断轨迹不作为性能或时间噪声验收。

将可见 cube 轮廓合成一个投影多边形的候选尚未通过数值审计。实机见证有 52 次无效方向／未命中，其中两次远离 cube。独立重建同一几何并在同一扇区 CDF 内双精度有界求逆后，52 次全部命中；[重放记录](../../../builds/light-sampling/20261108-eight-hour-exploration/independent-silhouette-witness.json)支持求逆数值问题，不是轮廓几何不可采样。[CPU float32 重放](../../../builds/light-sampling/20261108-eight-hour-exploration/silhouette-f32-sectors.json)中，一个原本约 4.75e-14 的末扇区面积放大至约 1.17e-10，导致接近 1 的随机数选错扇区；这不是 GPU 逐位重放，不能认定所有失败都来自同一机制。该见证作业最终场景恢复失败，原件仅用于诊断，不计入画质／性能排名。

后续远场候选 `480550f` 按几何条件选择在一个轴向平面的 cube 轮廓上均匀采样，再用真实面积到立体角 Jacobian 计算 PDF；近场和掠射回到原路径。讨论端用全部八个角的独立凸包，并在真实可见 cube 面积分 proposal，1,207 个合格输入覆盖 26 方位区域，归一误差最大约 1.33e-12，见[独立面域积分](../../../builds/light-sampling/20261108-eight-hour-exploration/independent-far-plane-integral.json)。这只证明双精度几何归一性，实际 GPU 支持、纹理／遮挡方差、速度和原路径自身失败率仍需实机核对。

[单样本 BRDF／选灯 MIS 余量筛查](../../../builds/light-sampling/20261108-eight-hour-exploration/offline-brdf-mis-headroom.json)也未给出这些失败点的通用修法。普通投影面上 `p_BRDF/p_cube` 为常数，小投影面积分支用几何上下界；将固定 M2 代入混合密度，50/50 对 anchor 的新红柱点约增至 `1.30–1.31` 倍，顶面约降至 `0.81`，moving 点多为 `1.79–2.60` 倍，砂岩墙约 `1.16` 倍。它仍可能适合其他近灯／稀疏场景，但不能仅凭互补直觉加入本轮默认。此筛查假设两个 proposal 评价同一目标积分，尚未验证现有同材质终点容差下的契约，未实现反向 PMF 或测量成本；[PBRT 接口](https://pbr-book.org/4ed/Light_Sources/Light_Sampling)说明反向 PMF 是实际 MIS 的必要部分。

#### 原聚类实验的起点与测量

用户根据最新实机对比，将优先级从前瞻／矩摘要转到聚类。已有同输入实测中，World Prefix + A + Near/Far 相对原始相机分组 + A + Near/Far 的整图 RGB 方差为 ls1 的 **1.333 倍**、ls5 的 **1.502 倍**；ls1 固定柱／墙 ROI 又分别改善到 **0.567／0.096 倍**。这确认分组变化足以产生区域间的收益与退化，不能再用少数改进点代表整图。用户另指出左侧红柱部分面改善、上方中间黄色受光顶面变暗；新区域需按实际接收几何定位，不能直接等同于旧两点。来源是[已复查的同输入分组记录](../../../experiments/light-sampling/20261108-grouping-control.json)。

本轮保留的契约是：**同一完整世界灯集合及通量下，相机位置、窗口地址与原子分配次序不决定簇归属**。固定 Morton 前缀本身不再是必须保留的拓扑。只把现有前缀树改成全局 Morton 列表再按同样前缀建树，可能没有改变聚类；只重排物理节点也没有修复此问题。灯集合改变后的重分组扰动另测，不将同输入稳定性扩大为流入／流出灯时也稳定。

首轮候选按实际灯分布做全局分桶空间划分，用现有通量和 AABB 面积构造 light-BVH 分割代价，再在建树时转换成现有四叉、32B 连续孩子表示。参考 [PBRT 的 light-BVH 构建](https://pbr-book.org/4ed/Light_Sources/Light_Sampling)中的通量、面积与轴向正则项；本实验不新增方向锥，按统一全方向界处理方向项。这是简化候选，不是对论文质量结论的复现。全局逐灯输入可跨 brick，brick 仍负责提取。普通几何 SAH 只作离线解释对照，不自动扩成 GPU 候选矩阵；H-PLOC 的并行构建器仍未选定。

聚类应让现有粗簇估权更可信，但其收益仍取决于权重与接收点；更小的 AABB／SAH 不等于更低采样方差。先用真实条件 M2 和退化区域筛选，再将可行候选接入实机、检查移动稳定性及完整构建成本。不同聚类不得使用接收点、实测 M2 或可见性作为运行时 oracle，也不按面朝向补倍率。一层前瞻及 K1／K2／K4 不进入本轮候选。

#### 聚类准则再筛：目标与诊断

用户要求继续找能同时保住红柱、顶面与 moving 侧面的分组，前瞻／K 保持暂停。当前[离线任务](light-sampling-clustering-repair-prompt.md#聚类准则再筛2026-11-08)固定 A + Near/Far 和原四叉宽化，筛通量／灯数乘对角线平方、空间中点、数量中位与通量中位六条规则，各比较全局逐灯和保留 brick 子树的上层构造。测试点、法线、M2 与遮挡不进入建树；没有参数、网格相位或测试朝向拟合。候选同时按全部指定内部点和工作量筛选，不能按平均胜场选默认。

依据与边界：[PBRT](https://pbr-book.org/4ed/Light_Sources/Light_Sampling)的面积代价是启发式，并非这里的逐灯采样方差目标；[Lightcuts](https://www.cs.cornell.edu/~kb/projects/lightcuts/lightcuts.pdf)提供通量乘包围盒对角线平方的全方向簇尺度度量。本轮只借用该度量测试 top-down 划分，不能混称为原算法复现。[Fast Agglomerative Clustering](https://www.graphics.cornell.edu/~bjw/IRT08Agglomerative.pdf)说明 bottom-up 可以产生不同的小簇，但它的 Lightcuts／追踪结果不能预言当前单灯采样收益；尚未据此选定或接通 H-PLOC。[Learning to Cluster](https://www.csie.ntu.edu.tw/~cyy/publications/papers/Wang2021LCR.pdf)主要学习接收区域的 cut 与概率，不是无需接收信息的全局树重建，这轮不引入它。

讨论端另做[逐节点方差分解](../../../builds/light-sampling/20261108-clustering-repair/review/cost_diagnostics.py)，[结果](../../../builds/light-sampling/20261108-clustering-repair/review/cost-diagnostics.json)使用真实 M2 归因而不参与建树。令 `S_v = sum_i(sqrt(M2_i))`，当前节点到达概率为 `q_v`、孩子条件概率为 `p_c`，局部损失为 `(sum_c(S_c² / p_c) - S_v²) / q_v`。逐层相加严格还原当前方差减逐灯最优方差；这是全局逐灯最优分布的分解，不是固定内部 proposal 的根层最优。

新红柱首窗的原全局 SAH 最大损失位于深度 4／3，占其超额方差约 42.2%／17.2%。深度 3 有一孩子包围盒包含接收点，独占 near 的半份概率，混合后份额 0.58445；按测得 M2 的最优条件份额为 0.00693。深度 4 的另一个通量仅 5 的孩子获 0.22040，参考份额却为 0.89631。问题同时涉及包围盒覆盖无灯空间与灯通量不等于接收贡献；对角线代价是否够用尚待本轮数据。moving side-b 的上层控制中，最大的剩余损失已在两个同通量叶灯间：实际约各半，但当前 M2 只在其中一盏为正。不能把这类有限窗口的零观测当永久不可见，也不能承诺仅改聚类消除全部方差。

低处簇的概率在 side-26／27 从树 A 的 76.07% 降至全量逐灯 A 的 14.43%／8.40%；立方体几何给 17.01%／14.45%。这区分了粗簇额外分配与剩余的无遮挡几何分配。该簇仍有 1570／1545 盏灯具有正几何积分而没有观测到正 M2；纹理与遮挡的影响尚未分离，不能据此将整簇置零。当前无需先恢复 visibility 引导，已有无遮挡修正空间值得优先处理。

对固定接收点，若每个父簇权重等于其后代逐灯权重之和，沿树的条件概率会消去中间层，得到全量逐灯分布。当前以总 mass 和大 AABB 重新估权不满足这个关系。最新世界前缀 A 的半径／余弦饱和、旧 near/far 的零近距独占是不同触发方式；共享问题是粗簇丢失内部贡献分布。上述同一逐灯 A 对照同时改善五点，支持一起研究这一层，而不按面朝向打补丁。

建议的查询过程先构造完整、不重叠的 cut，将几何跨度大、近远混合或跨接收半球的簇细化，再在 cut 节点间统一归一化、选一个簇并沿现有条件采样选一盏灯；实际 PDF 是簇选择与簇内选择的乘积。只凭当前 A 权重大或一层权重差小来决定细化，可能漏掉被低估的近灯簇；细化优先级仍需设计。可先以 16／32／64 项作离线预算探针，复用这五点的 M2，同时统计构建访问和每次查询工作，不新增 GPU 补测。预算是待验候选，有限 M2 不是运行时 oracle。

这借用 [Lightcuts](https://www.graphics.cornell.edu/~bjw/lightcuts.pdf) 按误差细化簇的结构思想；原论文近似照明的误差界不等于这里单灯采样的方差保证。若小 cut 能逼近全量对照，再讨论共享 cut **结构**以摊销构建，每个接收点仍使用自身位置／法线估权。为保持本轮移动目标，优先考虑固定世界空间分区；固定世界点的 cut／PMF 不应仅因镜头移动而跳变。屏幕 tile 共享需要另验分区变化，不能自行当作稳定。共享只摊销成本，不能补救一个仍然太粗的 cut。

本轮仅复用原件做诊断并更新讨论记录；未改 shader、默认或灯内采样，未派发新的实现／GPU 实验。上述 cut 仍是建议，实际项数、细化规则和共享范围未定。

### 前瞻、空间矩与多中心摘要（2026-11-08）

三种办法都在有限成本内近似簇内逐灯权重之和。区别在于查询时读取更细的已有节点，还是建树时准备更丰富的分布摘要。

| 候选 | 表达能力 | 成本与现有证据 |
|---|---|---|
| 下探一层并求子簇权重和 | 保留现有孩子之间的空间差异 | 四叉的每个内部候选最多评价四个孩子。已有一／两层跨 brick 对照改善五点，但两个侧面仍高于相机 A，低处簇的主要失配仍在。成本见[原生槽位复查](light-sampling-world-grouping-prompt.md#独立复查2026-11-01)。 |
| 单中心空间矩 | 均值给出能量中心，标量方差给出散布程度，完整协方差还描述伸长方向 | 当前 model 4／5 是中心加方差迹的 48B 节点。完整协方差有六个独立元素，替代标量方差增加五个浮点数，实际 stride 取决于布局。统计还需要映射成接收点权重。 |
| 固定 2／4 分量摘要 | 多个带独立 mass、中心和尺度的小分布可表达分离灯团 | 每个候选评价固定数量的分量，再求和。位置、mass、标量方差合计每分量五个 float，即 20B 净信息，对齐和支持范围另计。额外存储与构建压缩成本需要计入。 |

现有[空间矩与 SG 模型](../../../shaders/techniques/debug/LightSampling.glsl)已跑过旧五景实验，记录中有收益也有严重局部退化。[结果](light-sampling-reassessment.md#专用场景重跑1080p)只约束那些具体模型与输入。完整协方差、更高阶矩和多中心摘要仍属不同候选。[SG light-tree 论文](https://doi.org/10.1145/3680528.3687647)给出通量加权均值／方差的归并及 SG 估权，是已有单中心实现的参考。

从近似性质推断，接收点远离簇且簇张角较小时，低阶矩容易发挥作用。近处的距离权重变化快，半球边界又带来截断，少量矩难以保留少数近灯或相互分离的灯团。完整协方差可以区分球状与细长分布，但有限矩不能唯一恢复多峰分布。单中心摘要的成败也取决于将这些统计变成权重的公式。

多中心候选建议每个分量保留自己的发光量、加权位置和散布尺度，查询时计算各分量的重要性后相加。这样不同距离和方向的灯团可分别参与估计。若分量恰好复制当前孩子，并沿用相同权重函数，其估权与一层前瞻相同，预存只能改变数据读取方式。新的质量空间来自更合适的分量分组或分量权重模型。可在每个固定父簇内部，合并孩子携带的摘要，再压缩至 2／4 个分量，将工作放到建树阶段供所有接收点复用。

压缩过程要保持总 mass，每盏灯的质量归属只能计一次。选择与合并顺序应由固定世界输入确定，同一灯集合不能因相机地址或原子分配顺序改变摘要。仅最小化通量加权空间误差，仍可能吞掉少量、对附近接收点很重要的灯，因此这些分量的拟合质量必须用完整 PMF 和已有真实 M2 检查。分量中心在表面背后时，其覆盖的灯可能仍在正面，零权重判定需要保守支持范围。摘要负责评估实际树分支，最终 PDF 按实际归一化分支概率累乘。

### 簇摘要实验独立复查（2026-11-08）

复查候选 `5d9e9c355` 的三个点组：核验 192 个原始文件的 SHA／长度，从原生统计图独立提取全部 12 个点窗，与跟踪参考包逐项一致；逐像素二阶矩恒等式最大相对误差 4.25×10⁻⁷。直接解析原生树核对可达节点、灯键、mass 和物理空槽，并核对接收像素的材质、原点／法线及已有颜色／深度约束。三个冻结来源的 shader 差异仅为 fixture 数据及绑定，未混入新的估权实现。

[独立复算脚本](../../../builds/light-sampling/20261108-cluster-summaries/review/recheck.py)使用另一份逐对搜索保留真实分量成员，重建三个树的 K1／2／4 分量；与提交分量逐项一致，归并数和候选对数量一致。重新从公式求权重、遍历 72 个完整树分布并计算含逐灯对照的 84 个方差，均与报告一致，正 M2 支持失败为零。另复算 60 个查询成本案例的节点／分量均值及最大路径和各布局容量算式。[复查数组摘要](../../../builds/light-sampling/20261108-cluster-summaries/review/independent-review.json)与跟踪索引保留范围和哈希。

分量成员揭示了具体失配。side-27 的节点 153 在 K1 下将关键近灯与其余灯合为 17 灯分量，`dot(n,mu-origin)+sqrt(2*variance)=-3.879`，余弦项降至 0.001；K2 把该灯保留在 4 灯分量，余弦项为 1。top-28 的节点 70 在 K4 下把关键近灯放入 76 灯分量，中心高度 29.379、接收点高度 76.003，半径约 37.721，半球方向的“高度＋半径”为 −8.903，余弦项也降至 0.001；K2 的对应值为 18.304，余弦项约 0.375。原节点 AABB 的半空间检查通过，灯集合和正概率支持仍保留；失真出在后续分量估权。统计矩守恒并不保证方差球包住少数近灯，增加分量数、缩小方差也可能进一步低估它们。

接受这轮指定点的筛选证据，不接受任何当前摘要作为五点修复。K2 对两侧面已接近相机 A，但方差仍高约 14%／29%，对 top-28 又比前缀 A 高约 55%。这限定于当前 Ward 合并与球形核，未否决所有矩／多中心模型。ls1 是新灯集合的同输入对照，不能追认为旧 3,921 灯 near/far 失败批次的直接复现。M2 仍是有限样本估计，未观测贡献不能据此当作严格不可见。

额外峰值分配使用 269,764 个原生槽位的完整临时容量；三个点组实际可达节点为 7,490／7,490／18,119。这是所选直接索引布局的成本，不是摘要算法的内存下界。压紧或融合构建的成本尚未验证。复查未执行新的 GPU 工作，不能据此判定等时间画面收益或连续移动稳定性；下一步设计需解决近场及半球边界处的重要成员被摘要低估的问题。

## H-PLOC 全局聚类候选

该候选目前搁置，以下保留其范围与研究上下文。

已确认的范围是允许跨 16³ brick 对发光体做全局聚类。Brick 负责提取光源，不限定最终灯光树的分组；
这个决定记录在实验分支 `5c022ba1`，H-PLOC 构建器尚未实现。

现有实验已经有一棵覆盖当前体素范围的全局灯光树；二叉选项对应全局二叉树，当前默认则是四叉。
构建时每个 brick 先形成完整子树，再按固定 Morton 层次合并各 brick 的根。
因此跨 brick 的祖先节点早已存在，但不能只取相邻两个 brick 中的部分光源先组成一个局部簇，
同时把这些 brick 的其余光源留在簇外。这里的“全局聚类”指解除完整 brick 子树这一分组约束，
并非首次建立全局根；H-PLOC 的候选合并仍受 Morton 范围和局部邻域限制。

当前待讨论候选是全局 Morton 有序灯列表、H-PLOC 二叉构建，再转换为供现有采样器使用的紧凑四叉树。
[H-PLOC 论文第 3.4 节](https://gpuopen.com/download/HPLOC.pdf#page=8)已经提供宽树转换：
逐次展开表面积最大的内部子节点，直到得到所需数量的孩子或全部成为叶子。论文的完整流程输出四叉树，
内部仍先构建二叉树，再执行独立转换 kernel；二叉构建与宽树转换分别可以只用一次 kernel launch。
这不等于原生四叉聚类，也不等于整条准备流程只有一次 dispatch。省略二叉中间拓扑需要额外算法改造，
并不是将论文的一个分叉数参数设为四即可。

论文的光线追踪结果不能直接证明本项目的灯光采样方差更低。首轮候选比较保留当前灯集合、灯内采样与节点权重，
关闭 visibility 引导和前瞻；这些是讨论起点，尚未形成实验派工。

下一轮需要收敛的问题：

- 合并准则：先沿用合并后 AABB 表面积，还是引入面向灯光采样的目标；后者会同时改变拓扑构建目标，需说明归因。
- 二叉转四叉：论文的最大表面积展开规则可作为首版候选；待核对临时二叉索引到现有连续子节点布局的写出与调度。
- GPU 执行：核对全局 Morton 顺序生成、临时容量、subgroup 能力和跨工作组发布；避免把论文的执行机制当成已有 GLSL 能力。
- 实验判据：同时记录完整准备与建树成本、initial sampling 耗时、原始样本质量及 PDF／灯集合一致性。
  不能只比较核心构建 kernel，也不能把分组更紧凑当作降噪结论。

### 对采样质量的预期

目前没有 H-PLOC 的采样质量实测，不能认定有提升。它是值得比较的拓扑候选，收益仍是假说。
当前节点权重使用聚合发光强度、AABB 中心、包围球半径与接收点法线近似整个子树的贡献。
如果聚类减少跨空隙的大包围范围，或允许相邻 brick 的局部灯群单独成簇，可能降低分支概率的估计误差。
这种机会更可能出现在近场、稀疏或分布不均的灯群；它不保证每个接收点都受益。

H-PLOC 的面积合并准则不使用接收点、法线、发光强度或真实可见性。面积更小不保证上述权重更接近实际贡献，
也不能专门区分隔墙的灯。当前叶子还是同尺寸单位立方体，基线已有 Morton 空间分组，
不能照搬论文在不同尺寸几何体上的 BVH 质量收益来预测降噪幅度。
在灯内采样和真实贡献定义固定、support 与 PDF 正确的前提下，拓扑变化改变采样方差，目标均值不变。

已有五场景空间分组对照（实验记录提交 `181878b9`）本身结果混合：无前瞻时，
场景 1 暗部方差约增加 14%，场景 2 约降低 7%。这说明分组值得研究，但不是 H-PLOC 的收益证据。
首轮判断应看同灯集合、同四叉数和同节点权重下的采样误差／方差与贡献尾部，之后结合完整构建成本做等时间比较。
树面积、SAH 或可见命中率只能辅助解释；不能替代采样质量指标，也不能据此认定 H-PLOC 可以取代前瞻。

## 范围与决定

- 按纯 Iris shaderpack 设计，不依赖修改 Iris 或配套 mod 来提供发光几何。
- 当前关注 NEE 的光源选择与 visibility 引导。模型几何、逐 quad 存储、UV、cutout 判定和选中光源后的精确表面采样暂缓。
- 重要性估计先将大部分 MC 发光方块视为全面发光：点光源或球光源近似即可，立方体是后续更精确的模型。
  发光方向锥、发光方向 vMF 和位置与法线的交叉协方差不进入首轮实验。
- 接收点法线、BRDF 和出射方向仍影响重要性。光源全面发光不代表这些项可以忽略。
- 光源选择与选中光源后的条件采样分开处理。廉价的 proposal 近似不能悄悄改变实际光源贡献的定义。
- 优先用 visibility 统计修改分支概率，暂缓额外的随机子树剪枝。
- 先验证普通 NEE，再接入 ReSTIR、时域复用和降噪。

## 数据归属与流程

light BVH 归属于发光体集合；visibility 统计归属于接收点所在的空间 brick。二者独立，
不在每个灯光树节点上复制所有接收 brick 的统计。

| 顺序 | 阶段 | 用途 |
|------|------|------|
| 1 | 提取光源并构建层次 | 建立只包含发光体的树；光源提取细节暂缓 |
| 2 | 准备 visibility 统计 | 从各活跃 brick 的有效 shading 位置抽样，记录各方向首次遮挡距离 |
| 3 | 遍历灯光树 | 结合光通量、几何与 BRDF 重要性、brick 的可见性估计选择叶子 |
| 4 | 计算真实光源贡献 | 按需采样选中光源，追踪真实可见性，用实际采样概率计算估计值 |
| 5 | 更新统计 | 首轮先收集并冻结统计再评估；增量更新留待后续实验 |

## Light BVH

### 初始表示

从只包含发光实例的紧凑二叉空间树开始。Morton/LBVH 构建是基线候选，并不表示它的采样质量或 GPU 更新成本最优。
叶子标识光源；内部节点聚合空间包围范围和总光通量。具体打包、构建、refit 和光源标识仍待实现阶段确定。

不直接把体素占用层次当作灯光树。其占用查询职责和 64 叉结构不能证明它适合灯光采样。
更宽的树减少层数，但增加每层的子节点读取和重要性计算。

按全面发光的点光源近似，一个簇理想的无遮挡标量重要性正比于：

$$
I_C(x)=\sum_{\ell\in C}
\frac{\Phi_\ell}{4\pi r_\ell^2}
f_r(x,\omega_\ell,\omega_o)\max(n\cdot\omega_\ell,0).
$$

节点保存的是这个求和的近似，而非精确值。彩色光通量如何标量化、近场距离如何正则化仍待确定。
AABB 加光通量是首个简单候选；若空间高斯统计能胜过相同成本的更细树遍历，再考虑采用。

### 根据查询位置细化

远处紧凑簇可以使用廉价聚合。近处或范围大的簇、跨接收面地平线的簇、覆盖窄 BRDF 波瓣的簇，
可能需要在归一化竞争分支权重之前细化。选错父分支之后才精细采样，无法追回已在父节点分配错的概率。

查询 visibility 必须考虑簇的方向范围和距离范围。只查簇中心，可能压掉门洞后可见的子光源，
或混淆墙前与墙后的灯。首轮启发式是对宽簇弱调制，下降到紧凑簇后加强调制。
紧凑度规则和调制强度属于实验参数，尚未确定阈值。

## 方向遮挡距离统计

### 统计含义与起点分布

对于 brick B，D(x, omega) 表示从位置 x 沿方向 omega 到首次遮挡的距离。需要估计的是生存概率：

$$
S_B(\omega,r)=P(D\ge r\mid B,\omega).
$$

这个概率对选定的起点分布和角度滤波范围取平均。某个精确位置与方向的可见性是确定的；
这里的方差描述统计混合，不是场景本身随机变化。

首个候选从每个 16 x 16 x 16 brick 内实际发生 NEE 的 shading 位置抽取代表性样本。
这是初始实验选择；用户没有最终指定中心点或多位置采样。

| 起点分布 | 含义与限制 |
|----------|------------|
| brick 中心 | 只代表中心可见性；中心可能在实心几何内，或与查询点隔墙 |
| 多个有效位置 | 代表这些位置的平均可见性，仍可能混合不同房间 |
| 实际 shading 位置抽样 | 更贴近查询负载，但随视角与路径负载变化，需要更新 |

提高 SH 阶数不能恢复跨墙共享一份记录时丢失的起点信息。
实际查询的方向和距离从当前 shading point 计算，但查出的统计仍代表整个 brick 的混合起点分布。

### 有界距离变换与两个矩

使用带正距离尺度 s 的单调变换：

$$
T(D)=\frac{D}{D+s},\qquad T(\infty)=1.
$$

s 不是硬距离截断。保存 T 随方向变化的一阶矩与二阶原点矩：

$$
m_1(\omega)=E[T],\qquad m_2(\omega)=E[T^2].
$$

每个矩用一组低阶 SH 表示。最大次数为 2 时，每组有 9 个系数，两组共 18 个 FP32 数，
即每个 brick 72 字节，不含样本计数、置信度、历史和更新存储。
精度与 SH 阶数仍是实验选择。变换会压缩远距离之间的差异，因此距离尺度影响有效距离分辨率。

查询距离 r 时重建均值和方差，再使用 Cantelli/VSM 形式的估计：

$$
t=T(r),\qquad \mu=m_1,\qquad \sigma^2=m_2-\mu^2,
$$

$$
\widehat S_B(\omega,r)=
\begin{cases}
1,&t\le\mu,\\
\frac{\sigma^2}{\sigma^2+(t-\mu)^2},&t>\mu.
\end{cases}
$$

对于一个定义明确的分布及其真实矩，这个表达式给出生存概率的上界。
有限采样、截断 SH 和跨起点混合，不能保证它是当前 shading point 的真实可见性上界。
两个矩无法唯一恢复距离分布、尾部或逃逸概率。这只是 proposal 启发式，
正的尾部也不能代替采样器对有效光源的覆盖。

SH 重建可能产生不合法的矩。对取值位于 [0, 1] 的变量，可行矩应满足：

$$
0\le m_1\le1,\qquad m_1^2\le m_2\le m_1.
$$

投影回这个可行集合只是数值修复，不会恢复保守的场景可见性界。
零方差可能使均值之外的尾部为零，完整采样器仍必须保留必要的 support。

### 射线结果与训练

确认的首次命中才是距离观测。追到光源或有限上限 R 仍无遮挡，只说明 D > R；
这是右删失数据，不能记作距离 R 处的命中，也不能认定 D 为无穷。
步数耗尽不能作为自由空间证据。离开体素网格只能使用明确选定的边界模型，
不能证明网格之外的 MC 世界没有遮挡。

首轮从抽取的 shading 位置发射专用均匀球面探测射线，建立统计后冻结，
再用另一批查询样本评估。合成场景应明确边界外的几何，使真实命中和真正的 miss 可以区分。

现有 NEE 射线的方向分布受灯光选择影响，而且往往在选中光源处停止。
直接累加进 SH 会改变想要的统计含义。复用这些射线需要适当的采样权重或拟合处理，
以及对删失观测的处理，暂缓到后续。

在线更新必须保证生成样本时所用的统计与记录的概率一致。
读取上一帧状态、单独累积当前帧是一种可能实现，并非已经选定的资源布局。
几何编辑、新活跃 brick、负载变化和历史失效留待后续实验。

## 采样概率与估计器

令 q0 为在所有可能产生贡献的光源上都有 support 的基础树分布；
qv 使用 visibility 调制后的节点权重：

$$
w_C=I_C\,\widetilde v_C,\qquad
p_v(C\mid P,x)=\frac{w_C}{\sum_{j\in children(P)}w_j}.
$$

可见性因子包含选定的簇范围处理与统计置信度处理。没有可用统计时使用中性的 visibility。
如果所有子节点权重都为零，仍须定义归一化且有 support 的分支规则，使用基础分支概率。
未知可见性不能被当作贡献必定为零的证据。

每棵树的叶子 PMF 都是路径分支概率的乘积。通过混合完整分布保留探索：

$$
q(\ell\mid x)=\alpha q_0(\ell\mid x)+(1-\alpha)q_v(\ell\mid x).
$$

Alpha = 0.1 只是实验起点，不是调优后的默认值。该混合保证：

$$
q(\ell\mid x)\ge\alpha q_0(\ell\mid x).
$$

在每一层分别混入基础分支概率，不具备相同的叶子级保证；
最坏情况下，相对保护会随深度衰减。对选中的叶子计算包含两个分量的完整混合 PMF，
不能只除以选中采样技术自身的概率。

在真实贡献为 C_l 的离散点光源实验中，估计值为 C_l / q(l)。
加入表面采样后，还须计入其条件密度和相应测度转换。
真实可见性与实际发光体模型属于 C_l；学习得到的生存概率只用于 proposal。
当 support 和概率正确时，不精确的 proposal 改变方差而不使这个估计器有偏。
这不自动证明后续 ReSTIR 复用或已有追踪终止近似的正确性。

额外 roulette 要把存活贡献除以继续概率。随机删除子树后只重新归一化幸存者，并不是已成立的估计器。
共享一个随机距离阈值还会让剪枝事件相关，不能把边际存活率当作独立概率相乘。
roulette 可以节省工作，但会提高每次尝试的方差，须单独做等时间评估。

## 首轮实验

各版本固定灯光树、光源功率、场景、接收点查询和训练射线来源。

| 版本 | Visibility 表示 | 回答的问题 |
|------|-----------------|------------|
| A | 不使用 | 基础采样方差与成本 |
| B | 每个 brick 的高分辨率方向与距离直方图 | 空间共享的距离统计本身是否有效 |
| C | 同一批训练样本压缩成 SH 一阶矩和二阶矩 | 压缩是否保留了收益 |

B 是昂贵的实验参考，不是生产功能。如果 B 有效而 C 无效，检查表示损失。
如果 B 也无效，先检查起点混合、簇查询和可见性权重，再考虑提高 SH 阶数。
先冻结训练，不让各版本自己的反馈产生不同训练集。

首轮使用三个场景：

- 无遮挡的近灯与远灯：暴露纯开销和无谓方差。
- 同一个 16 立方 brick 内被墙分开的两间房：暴露起点依赖丢失。
- 小门洞后有很亮的远光源：暴露过度抑制和极端贡献权重。

离散测试以全灯求和作为参考，测原始估计值。检查 PMF 归一化、多随机种子的收敛、
相同样本数下的误差及贡献权重尾部。均值处于 Monte Carlo 不确定性内是证据，不是无偏性的证明。
可见命中率只是诊断指标：多采样容易看见的暗灯，也能提高命中率，却可能使光照估计更差。

离线实验可以确认统计价值。GPU 验收必须把探测射线、统计构建与更新、树遍历、最终 shadow ray
全部计入等时间误差比较。CPU 耗时不能证明 GLSL/Iris 性能。
先理解静态采样行为，再加入移动、几何变化、冷启动和 ReSTIR。

## 2026-10-29 实验结果

首轮 CPU 实验已完成。在本轮设置下，最大次数为 2 的 SH 候选没有表现出稳定收益。
这是合成场景中的统计结果，不是 Iris 或 GPU 性能结论。可见性引导继续作为实验方向；
采用这套 SH 表示之前，先处理几何节点重要性近似与有限前瞻。

### 协议与对照

[采样实验脚本](../../../scripts/light_sampling_experiment.py)在每个场景中使用 512 个全面发光点光源、
256 个漫反射接收点、不透明 AABB 遮挡体，以及全灯求和参考。
每个共享统计的训练种子使用 64 个独立起点、8,192 个等立体角方向分桶的中心，
即每场景 524,288 条探测射线。角度网格是确定性的数值积分。
训练种子为 11、29、47；alpha 为 0.1，距离变换尺度为 16 方块。
使用 float64、Python 3.14.7 和 NumPy 2.4.6 计算。

高分辨率参考在每个角度分桶中保留原始距离，并查询其经验生存函数。
另增加第四种表示：在相同方向分桶中只保留两个矩，不做 SH 压缩，
用来区分两矩近似与角向压缩的影响。所有版本共用训练距离、树和接收点。

节点采用光通量加权中心，以及包住所有后代光源位置的球。
当半径与距离之比超过 0.5 时，不使用 visibility 调制。
紧凑节点在包围球角范围内查询五个方向，距离使用包围球最近距离，
调制强度为 (1 - 半径/距离) 的平方。这些是具体的初始启发式，并非已证明最优的簇查询。

下表指标为所有接收点的精确单样本方差之和，除以基础版的对应值。
在各接收点使用相同样本数时，它也等于期望图像 MSE 的比值。
范围来自三个训练种子，不是跨场景置信区间，且未计构建与查询成本。

| 场景 | 距离 CDF | 方向分桶两矩 | SH 两矩 |
|------|----------|--------------|---------|
| 无遮挡 | 1.003 | 1.003 | 1.000 |
| 同一 brick 内的两间房 | 1.069–1.094 | 0.987–0.992 | 1.031–1.219 |
| 门洞后的远处亮灯 | 0.968 | 0.973–0.975 | 0.999–1.005 |

### 原因诊断

[冻结数据诊断脚本](../../../scripts/light_sampling_diagnostics.py)区分了三类损失：

- 让探测起点与每个查询点精确匹配后，双房场景的距离 CDF 方差比降至 0.948。
  起点混合在这个场景中确实产生了明显损失。这个对照不表示要实现逐像素缓存。
- 保留高角分辨率、只压成两个矩，在本轮中比投影到最大次数为 2 的 SH 更稳定。
  该结论针对当前 SH 拟合、可行矩修复、距离尺度和查询规则，不能排除所有 SH 或矩表示。
- 不使用 visibility，只把节点权重向下多聚合两层，
  无遮挡、双房和门洞场景的方差比就分别降至 0.577、0.815、0.762。
  几何节点重要性近似本身已经带来相当一部分方差。

在相同两层前瞻下，方向分桶两矩在双房场景得到 0.789–0.796，
在门洞场景得到 0.691–0.695，相对对应的纯几何对照还有额外收益。
SH 在门洞场景得到 1.712–1.719，约为纯几何前瞻对照的 2.25 倍方差。
更精细的树评估可能暴露原先被粗节点调制掩盖的统计误差。

完整叶子聚合是昂贵的参考对照。起点匹配且使用高分辨率距离 CDF 时，
双房和门洞场景的方差比分别为 0.075 和 0.0069；使用精确可见性时为 0.062 和 0.0034。
这些对照说明仍有统计收益空间，但需要逐灯工作或无法廉价得到的知识，不是生产采样算法。

### 正确性证据与限制

共享统计与起点匹配两次运行各执行 160 组 Monte Carlo 检查，每组 65,536 个样本。
均值与参考的最大偏差为 2.35 个解析标准误。
实际树遍历产生的 PDF 与枚举混合 PMF 一致，PMF 归一化且满足 alpha 倍基础分布的 support 下界。
独立枚举盒面交点的方法核对了每场景 128 条连接，并包含门洞可见和被遮挡的明确正反例。
一个错误使用不完整条件 PDF 的双灯变异得到 2，而正确结果应为 11，该错误被检查拒绝。

最大次数为 2 的 SH 候选没有通过收益比较。未改动 shader，也没有替换旧生产路径。
FP32 行为、动态更新、ReSTIR 接入、目标 Iris 编译、视觉验收和 GPU 等时间收益均未验证。
下一轮应比较有限几何前瞻与紧凑的正值方向表示；当前结果不支持立即把这套 SH 布局接进光影包。

## 暂缓方案与未决项

- 空间 SG 统计可能改善与方向 BRDF 的积分，但增加运算成本，也可能丢失空间各向异性或多峰结构。
  应与相同成本的有限前瞻细化比较；在全面发光假设下，发光方向 SG 不是重点。
- 学习分支修正、神经 proposal 和 ReGIR 留作后续选择。它们不能免除有效基础分布、
  明确的概率计算及更新成本核算。
- 对固定的标量子树估计器 Z_C，在分支成本相同时，最小化二阶矩给出与 sqrt(E[Z_C^2])
  成正比的分支概率，不一定与 E[Z_C] 成正比。这与已有 variance-aware guiding 有关，
  不是声称新发明，也不能直接套用到最终 ReSTIR 估计器。
- 起点抽样、SH 阶数与精度、距离尺度、探测预算、置信度处理、簇范围查询、
  探索权重和更新周期仍属于实验选择。
- 光源提取、树打包与构建更新、精确立方体或表面采样、透明度、UV 和 cutout 仍是暂缓的实现约定。

下一轮实验应处理上文识别出的节点近似与方向表示损失。
离线实现不代表已经建立运行时采样器、GPU 收益或视觉验收。
