## 先行诊断与独立消融

先修复审计寻址，用实际分辨率确认槽号唯一且不越界；包含一次 1080p 审计检查，不要求重跑旧四组叉数／前瞻配置的完整矩阵。
本次重跑质量主矩阵使用专用 preset 的原生 1080p。未重采集的旧 1080p 结果保持“需复验”，不能由新审计检查追认其质量。
在当前四叉基线上重建真实选灯分布、背面概率、叶子公式参考、无遮挡立方体参考与分深度／分支偏差，
不能继承旧二叉的百分比，也不能仅比较分布中位数。旧反例按世界位置和法线复现或选择等价近灯点，不能依赖变化后的固定像素槽号。

两项诊断变体均保留 32B、原始 mass、距离分母、Morton 四叉、立方体采样和随机数策略：

| 变体 | 唯一变化及其对照 |
|------|------------------|
| A：严格半空间排除 | 相对原权重，仅将整个 AABB 位于接收面背后的节点权重置零，其余余弦处理不变 |
| B：AABB 余弦估计 | 相对 A，仅替换余弦估计，提取已有改权重分支中的投影范围近似，不带入其新 mass 或新距离项 |

令 `h = dot(normal, delta)`、`e = dot(abs(normal), halfSize)`、`d2 = dot(delta, delta)`。
A 的几何判据为 `h + e <= 0`，实现时保守处理舍入，不删掉近切面正贡献的 support。
B 沿用 A 的判零；其余节点用 `h >= e ? h : (h + e)² / (4e)` 作为截断高度，除以
`sqrt(max(d2, 0.25))` 后夹到原有 `[0.001, 1]` 范围。距离分母仍为原来的 `max(d2, radius², 0.25)`。
这是用于隔离原有余弦近似的诊断模型，不是精确立方体积分或已接受的新默认值。

当前选灯循环假定孩子总权重为正；引入严格零权重时必须同步处理全部孩子为零的路径。
这种路径返回明确零贡献结果，不重试，也不除以零。主机审计将零结果的概率计入归一化，
检查 `sum(q_leaf) + q_zero = 1`，而非强迫每个接收点的叶子概率之和为 1；正贡献叶子仍须有正 proposal。
这里 `q_zero` 仅指选灯阶段的空结果，不能把选灯后遮挡等导致的零贡献重复加进归一化。
对完全零贡献的参考点单独报告，不强行归一化空目标。验证全背面、混合子簇、跨接收平面和近切面条件。

按真实返回路径增加互斥的终止原因计数：无灯／选灯零结果、立方体方向生成失败、余弦或目标交点无效、
追踪耗尽、未命中、非发光首命中、代理内无表面入口、发光首命中与目标不匹配，以及成功目标命中。
成功命中后再区分实际纹理贡献为零与非零；保留非有限值计数。说明计数分母，核对终止分类总数与接收点数一致。
不要把所有目标不匹配都直接称为遮挡；计时时关闭新增诊断写入和参考探针。

如果分类计数和无遮挡参考仍不能解释 room2 暗部或近灯尾部，在少量固定真实点补逐灯条件样本，
记录带真实可见性的贡献均值及二阶矩，与无遮挡参考比较并给出采样不确定性。
只扩充能区分剩余原因的点和样本；这项定位不实现 visibility 引导或全图逐灯扫描。

## 实施前的公式与数据约定

已选择的是三个模型族，部分实施数学仍未确定。接入 shader 前，在研究记录中为每项写出简短规约：
实际公式、参数含义、有限定义域行为、support，以及最终估计器采用的概率。
在这三个模型族内完成普通选择并记录理由；若必要处理会改变候选含义或固定的贡献约定，回到设计讨论决定。

| 候选 | 必须补齐的准备 |
|------|----------------|
| 近／远距离混合 | 定义论文两套分别归一化分布的四孩子扩展，包括一个或多个最小距离为零的情况。沿用当前余弦处理以隔离距离变化；混合概率，不混合原始权重。 |
| 球形权重 | 给出一条使用通量加权中心与标量空间离散程度的具体几何公式，定义单位立方体叶子有限范围及其测度、归并、距离处理与 support；本候选不执行 SG 积分。 |
| 漫反射 SG | 与球形候选采用相同叶子空间矩、归并和节点布局；根据重评文档链接的论文及勘误，明确全向发光适配与漫反射截断余弦积分。处理小／大锐度、近场极限和数值下溢，不暗中丢失贡献 support。 |

保留 AABB 并附加一个 vec4，是候选 2／3 的直接 48B 布局；候选 1 与原基线维持 32B。
球形与 SG 使用相同表示以便归因，替换为 32B 球形布局不属于首轮。
将节点 stride、SSBO 容量、清零、叶子初始化、全部归并层、消费者与主机采集解码作为同一数据约定修改；
尤其要核对资源声明中依赖节点尺寸的 `bufferObject.12` 容量。

实机运行前，用小规模独立主机参考检查归一化与 support：接收点在单个或重叠孩子包围范围内、
靠近立方体与地平线、远距离簇、mass 差异大，以及立方体有限范围。
SG 积分在代表性参数上使用独立数值积分或适当的高精度参考；只复制 shader 表达式不构成精度检查。

- 使用现有独立单样本朗伯直接光路径。没有天空／太阳贡献、radiance cache、path guiding、ReSTIR、空间复用、
  TAA 或降噪；不通过改变随机数策略改善某个候选的图像。
- 关闭几何前瞻与 visibility 引导。不将 tree cut、H-PLOC、RIS／ReGIR、BRDF／选灯 MIS 或新灯几何混入矩阵。
  Visibility 与 H-PLOC 保持暂缓。
- 比较原权重及全部三个候选，另完成前置 A／B 消融。主权重矩阵的原采样基线只修审计，不混入 A／B，
  也不自动测试组合。保留独立余弦 BRDF 参考，帮助解释图像与均值能量；不能用它代替原灯光树对照。
- 性能矩阵使用四叉。保留已有二叉／八叉功能，对受影响的编译与容量分支做必要检查，不扩展成分叉数性能扫描。

## 实现与运行时主链

| 顺序 | 工作 | 必须得到的结果 |
|------|------|----------------|
| 1 | 审计修复、四叉重查与分类计数 | 720p／1080p 寻址正确，当前基线诊断可复查，失败原因不再混为命中率 |
| 2 | A／B 消融与其必要编译、采集、计时 | 单独归因半空间排除和余弦变化，零结果及实际 PDF 正确 |
| 3 | 三项公式与主机参考准备 | 模型明确，检查有独立意义，未决问题显式记录 |
| 4 | 构建器、资源与采样器接入及编译 | 每个候选到达原始直接光输出；布局／PDF、维护源／生成物一致，Target Iris 通过 |
| 5 | 匹配条件的质量与计时对照 | 三项候选都有原件和分场景结果，包括失败与退化；必要时补定点可见贡献参考 |

通过维护中的选项源注册设置，需要时从 scripts 目录运行常规生成器，不直接编辑生成 wrapper 或 binding。
GLSL 索引与 dispatch 声明遵循 shader 规则。
现有[静态语法工具](../../../scripts/light_sampling_wide_syntax.py) 使用 stub 和旧输出目录；需要时适配，
仅在 IDE 诊断不可用或已要求外部验证时使用，不能把它当作 Target Iris 或 GPU 正确性证据。

使用不加载 profile 的 PowerShell 7，优先最新可用 GraalVM JDK。时间不敏感的编译及长后台准备使用最低进程优先级，
benchmark 保持可比条件。若全局 Gradle home 出问题，停止并报告，不切换到其他 Gradle home 绕过。

使用 Vibris 做实机编译、采集与测量。确认加载的 shader pack 确实来自 wt4，记录 resolved revision 或 source hash、
有效设置、场景／preset hash 和分辨率。由当前程序注册及已加载程序定位相关 pass，不能沿用历史 wrapper 编号。
不重启 Minecraft 或启动器；安全恢复仍不可用时，保留已完成工作并报告缺少的运行时证据，
不能改用 replay 证据或宣称验收通过。

## 证据与验收

使用五个专用场景 preset：`light-sampling-1`、`light-sampling-2`、`light-sampling-3`、`light-sampling-4`、`light-sampling-5`。
核对它们仍存在及实际分辨率，方法之间统一使用匹配的原生 1920×1080 条件；不把旧宽树毫秒数当对照。
某 preset 缺失时报告缺口，不悄悄换成另一个名称的场景。

接受质量或计时样本前，核对灯集合与 mass hash、包围范围／孩子链接、overflow 和 exhaustion 计数、
节点 stride、有限值及包含零结果的完整 PMF 归一化。独立重建真实所选灯 PMF 与立方体条件 PDF，检查树与审计同帧来源。
旧二叉读取器或成功编译不能代替这些检查。
同 source／preset hash 不足以证明流式世界的几何相同。每场景质量、参考和计时须有前后完整有效分配的非空体素材料快照（含非发光遮挡体），
按 brick／local Morton 与 packed material 归一化比较，忽略未分配池槽。计时末尾直接 dump，不重新加载 shader 或另作预热；
活动 source UUID、加载时间、配置／preset 应与末项 profile 一致。发生漂移时保留并分开 cohort，采用有依据的一次稳定输入补采，
不把不同输入的质量与成本混合，不无限追赶几何。主机友好标签不能替代真实 effective MODEL／SAMPLING 核对。


针对[证据复查](light-sampling-reassessment.md#原始场景证据复查2026-10-31)中的失败模式，在少量真实接收点
分别记录整灯位于背面却得到的选择概率、树分布与同叶子公式全量归一化分布，以及固定 mass 的无遮挡立方体积分参考。
检查近灯／地平线尾部而非只有中位数。叶子公式本身也可能失败，不能把“更接近全量叶子公式”当作最终质量目标。
按前述先行任务单独完成 A／B 消融，并输出分深度／分支诊断；不把它们与区域 cut 的实现混在一起。

质量采集保留原始线性 1 spp 单帧、32 帧均值／方差及有效样本数。使用匹配的 warmup 与采集窗口，
以既有 256 帧质量 warmup 为起点。分开报告暗部、近灯或亮部尾部，以及低频空间误差。
保留非有限值与 incomplete 计数，不通过裁剪或静默删像素掩盖问题。对代表性裁剪区域使用充分收敛的参考，
区分参考误差与短窗口方差；各方法曝光与掩码一致，并保留底层原始数据。

计时时关闭审计原子操作，使用匹配的正／反顺序对照，初始沿用每项 128 warmup 与 128 测量帧的协议。
测量 initial sampling pass、全部必要准备／建树阶段、受影响的相邻 pass，以及稳定负载 sentinel。
计入空间矩构建与实际节点内存。写清统计量；阶段平均值之和不是中位数。
Initial pass 还包含立方体采样和追踪，不能描述成独立树遍历时间。
余弦 BRDF 不需要额外诊断建树，需区分实际执行的诊断开销与该方法必需工作。

先做等样本数，再做完整等时间成本比较。漂移或不确定性妨碍结论时再重复测量，不无故扩展矩阵。
范围内的数值或布局缺陷应修复并重跑受影响检查；support 或 PDF 无效的候选不能取得质量／性能接受结论。
