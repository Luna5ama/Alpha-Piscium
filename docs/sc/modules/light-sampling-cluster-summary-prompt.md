## 固定比较范围

主比较统一在完整世界前缀四叉树上，保留 32B A 节点作为基础表示。改权重的范围只覆盖实际 bounds 跨世界 16³ brick 的内部候选。brick 内及叶子继续使用 A，避免把外层摘要与灯内局部权重变化混在一起。

| 方法 | 本轮定义 |
|---|---|
| 世界前缀 A | 同输入主基线 |
| 一层前瞻 | 已有 `outer-lookahead-1`，每个跨 brick 内部候选用直接孩子的 A 权重之和，沿用已核验定义 |
| 单中心矩 K=1 | 每个跨 brick 候选保存一个通量加权中心和标量空间方差，使用下述球形核 |
| 两分量 K=2 | 每个跨 brick 候选保存至多两个分量，分别用同一球形核评价后相加 |
| 四分量 K=4 | 同上，分量上限为四 |

同输入原始相机 A 仍是附加质量对照。全量逐灯 A 作为聚合误差诊断标尺，可从现有源码重建。历史两层前瞻可引用，不扩展为本轮运行矩阵。SG、完整协方差、高阶矩、自适应 cut、visibility、H-PLOC 和 near/far 参数搜索留在本轮之外。

采用相同球形核是本提示词的首轮实验选择，用于隔离分量数量和压缩效果；本轮 K=1 只在外层生效，并包含 A 的整簇半空间判断，应明确区别于旧的全树 model 4／5。

## 分量生成与估权

每个叶子作为一个初始分量，mass 来自当前根可达灯，中心为 voxel low + 0.5，方差迹为 5/12，沿用[现有叶子矩定义](../../../shaders/pass/prepare/LightSamplingBuild.comp.glsl)。对每个 K 独立自底向上处理，每个父节点收集孩子至多 K 个分量，然后压缩至至多 K 个。K=1 必须复现直接对所有后代叶子求得的总 mass、均值和方差。

首轮固定使用增加加权平方空间误差最少的逐对合并。对分量 a、b，代价为 `delta = Ma*Mb/(Ma+Mb) * dot(muA-muB, muA-muB)`。每次选择最小代价对，合并 mass 与均值，方差按各自内部方差加中心偏移项归并，重复直到达到 K。直接孩子最多四个，所以每次压缩最多从 4K 个分量开始。实现可优化求最小值／维护候选的方式，但不能悄悄改变合并准则。

并列代价按组成分量的规范世界身份确定，例如其最小后代 `(worldX,worldY,worldZ,material)` 键。排序与 tie-break 不依赖原子分配地址、相机槽号或接收点。保存足以复查归并的分量信息。要求 mass 守恒、叶子质量不重计、统计非负有限，并用直接叶子统计核对各父节点分量合起来的一／二阶矩。固定输入改变存储／输入枚举顺序后应得到一致的规范摘要。

候选节点先使用其真实 AABB 执行现有 A 的半空间判断。整簇确定在接收点背后时权重为零。否则对每个正 mass 分量计算：

```text
delta = mu - origin
d2 = dot(delta, delta)
r2 = 2 * variance
c = clamp((dot(normal, delta) + sqrt(r2)) / sqrt(max(d2, 0.25)), 0.001, 1)
w = mass * c / max(d2, r2, 0.25)
clusterWeight = sum(componentWeights)
```

仅用原候选节点的保守 AABB 作严格半空间剔除。分量方差半径是有效尺度，不能当作所有成员的包围界；不要因一个分量中心在背面就将其置零。各分量权重求和后参与实际兄弟归一化，最后沿真实树累乘概率。分量仅用于估权，灯集合和主树父子归属仍由固定世界输入决定。

高精度离线参考与 float32 可实现表达式分别标明。复用[当前归并和估权实现](../../../shaders/techniques/debug/LightSampling.glsl)，核对绝对世界坐标下的数值误差。物理存储可只保留跨 brick 摘要，但生成它所需的 brick 内处理和所有临时数据必须计入构建成本。直接复制原孩子摘要只能作为一层前瞻等价性自检，不冒充新的 K 分量拟合。

## 五点质量与归因

每个主点使用两份不重叠的条件参考窗。恢复到上一轮数据时包括 side-27 的跨组重复双窗，总计 12 个点窗。需要补采时沿用前轮双点 mode 3、32 帧／8×4 batches 协议和指定原生 1920×1080 接收像素，保存前／中／后完整世界输入、实际原点／法线／albedo、树和 provenance。采样数从真实灯数和分辨率推导，保留零样本及缺失／非有限计数。真实纹理、灯内采样和 visibility 进入条件评价。

复用[矩提取](../../../scripts/light_sampling_point_moments.py)、[PMF 筛选](../../../scripts/light_sampling_point_screening.py)、[布局重建](../../../scripts/light_sampling_moving_analysis.py)和[权重参考](../../../scripts/light_sampling_weight_reference.py)。原件恢复后重用已经适用的验证，补采则重新核验 per-pixel 二阶矩恒等式与输入身份。跨树按世界位置／材质键和 mass 对齐，使用实际审计原点，避免重复添加法线偏移。

枚举全部实际叶概率和 null 概率，用 `sum(M2_l/q_l) - dot(sum(mean_l),sum(mean_l))` 计算 RGB 方差。正 M2 灯对应零概率时报告支持失败。禁止只保留有贡献灯后重新归一化。每窗分别列出相对世界前缀 A、相机 A 和全量逐灯 A 的结果，五点全部保留，完整数组可交回独立复算。

重点报告低处根子簇的概率、实际 M2 份额、主要惩罚灯以及贡献最大的几处分叉。将候选粗簇估权与其后代逐灯 A 权重和对照，检查少数近灯是否被分量压缩吞掉。sqrt(M2) 只可用于离线归因，不能进入分量构建或参数选择。K 增加时质量可非单调，保留反例，不以这五点调整系数或硬编码朝向。

## 成本与按需 Vibris 实测

所有方法首先报告同口径的静态成本。查询成本包括实际到达概率加权的每样本节点／摘要槽位检查、分量核评价、半空间检查和归一化工作，同时给出最大路径工作量。原生四叉节点有空槽，不能只数非空逻辑孩子。候选固定 K 槽位若要检查空分量，也必须计入。逻辑记录、物理槽位与字节数分列，静态检查数不称作显存事务或 GPU 时间。

存储分开列出净统计量、实际打包 stride、计数／索引、活跃摘要、分配容量、持久缓冲和峰值构建临时量。K=1 可复用父节点 mass；K=2/4 各分量的 mass 需要独立保存。给出一份可实现的具体布局与访问次序，不能只报告每分量 20B 净信息。构建统计覆盖所有必要层级的分量归并、候选对比较和临时读写，一帧一次的准备成本与每样本查询成本分开。CPU Python 耗时只标为离线分析耗时。

若候选有明确质量收益或值得判定的质量／成本取舍，可按用户授权自行做最小运行时实现与 Vibris 实测。冻结候选源码，复核实际载入的 source、revision、preset、设置、灯集合和相关 pass。优先在 moving-4 测世界前缀 A、一层前瞻及有价值的 K 候选，必要时补 ls1。常规计时优先 720p，指定点／PMF 核对可使用原生 1080p，明确用途并保持组内一致。

计入完整灯提取／建树／摘要准备，以及实际 [LightSamplingInitial](../../../shaders/pass/composite/LightSamplingInitial.comp.glsl) 路径的时间；独立摘要阶段单列，相关兄弟 pass 与稳定 sentinel 一并记录。条件、预热、帧数、统计量一致，使用相邻正反次序并按噪声需要复测。prototype 必须实际消费摘要并改变选灯概率，先将 GPU 诊断与离线参考对齐。计时场景若与 M2 cohort 不同，分别标明，不能直接当作同输入等时间质量验收。

离线结果已否决的候选可以止于静态成本报告。若运行时可实现性迫使改变核、压缩规则或支持域，应报告设计差额，不能用不同算法的计时给原方案背书。live 服务恢复失败只阻挡依赖它的部分，继续已有数据能完成的工作后回报缺口。生产默认是否提升仍由讨论端复查与用户接受决定。
