# 不透明表面混合 GI 实机验收

2.0 独立候选。[受验修订与原始记录](https://github.com/Luna5ama/Alpha-Piscium/blob/f10a01db5ddc2976401c83a8d947eb6660d2d389/docs/sc/development/hybrid-gi-acceptance.md)

冻结规格为 `48c9e1f0:docs/rendering/hybrid-gi.md`，基线为 `5ba8718d4`，实现为 `b59d5ef7`。Minecraft 1.21.11、Iris 1.10.6-vibris.3、RTX 3080 Ti，1280 × 720。每组回执保存了实际源码、设置、场景、pass 映射和编译结果。普通场景覆盖下表。用户将真实 Voxy 远景、远端距离写回和端点重建误差留待单独验收。

| 普通场景 | 实测结果 |
| --- | --- |
| 铁傀儡、半砖及前墙 | 无附加墙时，88,040 个样本同时取得两个正距离，按 0.015 格同面容差，误选较远表面的数量为 0。较近体素获选 4,749 次，较近屏幕获选 7,332 次，其余为容差内的样本。独立加墙对照中，原点 (49.0625, 66.0625, 49) 的屏幕、体素、选中距离分别为 3.125、2.084、2.084 格。原始图与接收像素见 `d26213fd`、`3b70deaa`。 |
| 网格边界 | 缩到 16 砖的网格后，在远墙机位观测到盒前 1,537、盒后 4,238、纯屏幕 1,758 个命中。带盒外区间的有限重连有 1,316 条通过，77 条在体素段被拒。正常离网后取得环境的样本有 256,034 个。诊断专用单步体素预算下，563,053 个耗尽样本保留零贡献，进入环境的耗尽样本为 0。 |
| 当前取光与反弹归属 | 镜头转开后，RC 启用时有 5,507 个离屏自发光体素命中，82,210 个离屏命中选择 RC。94,742 个同时具备可靠屏幕历史和 RC 的命中选择了 RC。关闭 RC 后两类 RC 选择均为 0，仍有 5,147 个离屏自发光命中。有效零 RC 压过非零历史的分支由合成输入覆盖。 |

| 滤波与空间复用 | `49afc6e1` 从降噪入口前读回 diffuse/specular 的全部 8 个 FP16 分量及最终图，RGB 均有限。镜面房间在旧版兼容布局上分别启闭空间复用，两幅最终图的 8 位 RGB 绝对差均值 2.74、P95 为 9。此数值包含采样与滤波差异。 |

## 720p 成对计时

镜面房间、相同设置，每臂预热 48 帧、采样 96 帧。下表为驱动 compute 时间 P50，单位毫秒。原始逐帧值和 pass 标识见 `09e53519`。

| 路径 | 基线 A | 混合 B | 混合 B | 基线 A |

| 初始方向 composite20 | 0.099 | 0.098 | 0.098 | 0.099 |
| 体素与屏幕尾段 composite21 | 0.400 | 2.039 | 2.038 | 0.401 |
| 有限重连 composite30 | 0.048 | 0.335 | 0.335 | 0.048 |
| 直射对照 composite13_a | 0.104 | 0.104 | 0.104 | 0.104 |

本次保留 4 格盒内近段与 128 步屏幕预算。额外 GPU 成本留给 2.0.x。此前 8 个入口、三组设置的离线编译和 601 条斜向解析平面对照仍适用。`gi-shadow-1-720p` 的地形稳定超时、超过 8 个 image 的首个诊断版本和配额拒绝的批次只保留失败回执。
